# بوت القاموس القبطي على WhatsApp

نسخة مستقلة من بوت القاموس: تبحث في بيانات القاموس المرفقة (أكثر من 16 ألف سجل) بالعربية والقبطية واليونانية والإنجليزية والفرنسية والألمانية. تعمل عبر WhatsApp Web باستخدام Baileys وتربط الهاتف برمز اقتران؛ لا تستخدم Telegram أو Cloudflare Workers.

## المتطلبات

- Node.js 20 أو أحدث.
- رقم هاتف تملكه ويمكنك ربطه بحساب WhatsApp عبر **الأجهزة المرتبطة**.
- تشغيل دائم على جهاز أو استضافة تدعم Node.js؛ جلسة Sandbox المؤقتة ليست استضافة دائمة.

## التثبيت والاقتران

```bash
npm ci
cp .env.example .env
# عدّل WHATSAPP_PHONE_NUMBER في .env: رمز الدولة والأرقام فقط، بلا + أو مسافات
npm start
```

ستظهر في الطرفية **رمز اقتران مؤقت**. أدخله بنفسك في WhatsApp على الهاتف: **الإعدادات ← الأجهزة المرتبطة ← ربط جهاز ← الربط برقم الهاتف بدلًا من ذلك**. لا ترسل الرمز لأي شخص. بعد نجاح الاقتران، تُحفظ بيانات الجلسة محليًا في `auth_info/` وهي مستبعدة من Git. احتفظ بها بسرية ولا ترفعها إلى المستودع.

إذا أردت قصر الردود على محادثات محددة، عيّن `ALLOWED_CHAT_IDS` في `.env` إلى قائمة JID مفصولة بفواصل. البوت يتجاهل المجموعات افتراضيًا.

## الأوامر والبحث

- `/start` و`/help`: تعليمات.
- `/stats`: عدد سجلات القاموس.
- أرسل كلمة مباشرة للبحث؛ تُعرض حتى 5 نتائج.

## الاختبار

```bash
npm test
```

## تنبيه تشغيلي

Baileys تكامل غير رسمي مع WhatsApp Web وليس WhatsApp Cloud API الرسمي. حافظ على تحديث الاعتماد، والتزم بشروط WhatsApp، واستخدم رقمًا تملكه. لا توجد أسرار أو رموز اقتران في المستودع. لا تضع مجلد `auth_info/` أو ملف `.env` في GitHub.
